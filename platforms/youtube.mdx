| | |
|---|---|
| **Caption limit** | 5,000 characters (description) |
| **Post types** | Standard video, Shorts |
| **Capabilities** | Publish · Analytics · Comments |
| **Connect** | Headless (`POST /v1/social/connect/youtube`) or dashboard |
| **Tokens** | ~1 hour, auto-refreshed |

**Requires a video** - a post without one is refused with `422 VALIDATION_ERROR` before anything is sent. YouTube's API has no community (text) posts.

**Privacy is read back.** After the upload, the privacy YouTube actually applied
is compared with `platform_options.youtube.privacy`. When YouTube set a
different one (for example it forced the video private), the post still
publishes and carries a `privacy_changed` entry in `publish_notes`, with the
reason "You chose Public, YouTube set Private."

See [all platforms](/platforms) for the capability matrix and media rules.
