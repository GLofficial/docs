| **Caption limit** | 500 characters |
| **Post types** | Text, image, video, carousel |
| **Capabilities** | Publish · Analytics · Comments |
| **Connect** | Headless (`POST /v1/social/connect/threads`) or dashboard |
| **Tokens** | ~60 days |

## Checked before publishing

These are checked before a post is sent; a post that breaks one is refused with
`422 VALIDATION_ERROR` and a message naming the rule:

- **500 characters, counted the way Threads counts them**: every emoji counts as
  its size in UTF-8 bytes (most emoji are 4, joined ones such as family emoji
  more), so a post with many emoji reaches the limit sooner.
- **Up to 5 links** in the text.
- **Up to 20 items** in a carousel.

See [all platforms](/platforms) for the capability matrix and media rules.
