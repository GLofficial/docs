| | |
|---|---|
| **Caption limit** | 2,200 characters |
| **Post types** | Feed, Carousel, Reels, Stories |
| **Capabilities** | Publish · Analytics · Comments · Direct messages |
| **Connect** | Headless (`POST /v1/social/connect/instagram`) or dashboard |
| **Tokens** | ~60 days, auto-refreshed |

**Requires media** — a text-only post is rejected. DMs use Meta's **24-hour messaging window**.

## Checked before publishing

Instagram's own caption and video rules are checked before a post is sent, so a
post that breaks one is refused with `422 VALIDATION_ERROR` and a message naming
the rule, instead of failing at Instagram later:

| Rule | Limit |
|---|---|
| Hashtags in a caption | 30 |
| @mentions in a caption | 20 |
| Reel or feed video | 3 seconds to 15 minutes, up to 300 MB |
| Story video | 3 to 60 seconds, up to 100 MB |

The video length and size are read from the file itself when you create the post.
A **story carries no caption**: a story with text still publishes, and the
response carries a warning that the text will not appear on it. Put any wording
into the image or video.
